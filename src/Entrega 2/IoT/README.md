# IoT e Sistemas Embarcados - TennisSync (Entrega 2)

Ambiente de firmware e circuito para a **Entrega 2**.

---

## 🎯 Metas da Entrega 2

- [ ] Incorporação de sensor de acionamento (pedal) para iniciar as tentativas de treino (conforme modelo da máquina de estados finitos).
- [ ] Módulo de áudio/voz para instruções corretivas em sincronia com o alerta sonoro e os LEDs.
- [ ] Validação física em protoboard real com o Arduino Uno.

Simulação Wokwi base: [Wokwi TennisSync Circuit](https://wokwi.com/projects/477109468016580609)
